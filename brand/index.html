Rules

Which file. Use -dark files on dark backgrounds (bone wordmark, brighter eyes) and -light files on light backgrounds (ink wordmark, deeper eyes). The stacked lockup (W over WOODFORD XR) is the square version for avatars and icons; W-over-XR is the compact alternative where the full name would be too small; the W alone is the favicon and the fallback below about 24 px.

Clear space. Keep at least the height of one W stroke (about a fifth of the mark's height) clear on every side. Minimum width for the horizontal lockup is 140 px; below that use the mark alone.

Don't. Recolour the eyes, swap red and cyan, add a gradient or shadow, outline the mark, rotate it, or set the wordmark in a live font. Use the supplied paths.

Mono. Where only one colour is available, use the mono files: the mark becomes the solid silhouette of both eyes, so the footprint matches the colour version exactly.
