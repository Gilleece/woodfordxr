Depthray 隐私政策

本页是 Depthray 隐私政策的简体中文译本，英文版本见 privacy.html。如两者有出入，以英文版本为准。

最后更新：2026 年 10 月 7 日（标明了应用收集的数据，将其与仅在头显上处理的数据区分开来，并说明了如何申请删除）。本政策适用于由 Woodford XR 发布的 Meta Quest 与 PICO 头显应用 Depthray。Woodford XR 是个体经营者 Sean Gilleece 的商号。使用条款（英文）另见单独页面。

简要说明

Depthray 没有自己的账户系统，不做数据分析，不做崩溃报告，也没有广告；Woodford XR 不保存任何用户数据库。应用会收集和处理少量个人数据，全部列于下文。它收集两项数据：您在 Meta Quest 上的 Meta 用户 ID，以及您在应用商店的购买与授权记录，两者仅用于确认您拥有本应用。它还会处理（但不收集）您添加的服务器信息，这些信息只保存在您的头显上，Woodford XR 永远不会收到；以及您选择发送问题报告时填写的内容。您可以写信至 support@woodfordxr.com，要求删除 Woodford XR 持有的任何与您有关的数据。

应用收集的数据、仅处理的数据及其用途

Depthray 收集两项个人数据：您的 Meta 用户 ID 和您的购买与授权记录；另外处理几项从不离开您头显的数据。下面逐项列出及其用途。

  • 您的 Meta 用户 ID（Meta Quest）。收集。Meta Horizon 平台通过用户 ID 识别登录头显的 Meta 账户。Depthray 每次启动时通过 Meta 的 Platform SDK 收集它，并只用于一个目的：确认您的账户已获得本应用的授权。它不会被显示，不会写入日志，不会由 Woodford XR 保存，除 Meta 之外不会发送到任何地方。
  • 您的购买与授权记录（Meta Quest 与 PICO）。收集。应用从应用商店收集这项数据：询问您的账户是否拥有 Depthray，以及是否已购买免费试用后用于解锁应用的那一项应用内购买；当您选择购买时，应用会打开商店自己的结账页面。这项数据仅用于解锁应用。应用把结果（是否已解锁，以及试用已使用多少）保存在头显上应用的私有存储中，不保存在其他任何地方。Woodford XR 永远不会收到它，也永远看不到您的支付信息，支付信息只保留在商店。
  • 您的服务器与设置。在头显上处理，不收集。您添加的服务器和共享、它们的密码和访问令牌、您的设置以及您的播放历史。您头显上的应用用这些来播放您的文件并续播。它们只保存在头显上：Woodford XR 永远不会收到、看到或保存您的密码或令牌，也没有任何途径获取它们。它们只会在应用登录所属服务器时，从头显发送到该服务器。
  • 问题报告（如果您发送）。仅在您按下“发送”时收集。您的留言、头显型号、应用版本、应用日志，以及您填写的电子邮箱地址（如有），仅用于调查问题和回复。这是唯一会到达 Woodford XR 的数据。

以上数据均不会被出售，不会为广告目的共享，也不会用于建立您的画像。

保留在您头显上的内容

Depthray 在头显上自己的私有存储中保存：您添加的媒体服务器和网络共享，其密码和访问令牌以头显自身的密钥库加密；您的设置；以及您的播放历史，以便影片从上次离开处续播。这些都不会发送给 Woodford XR 或任何其他人，Woodford XR 也无法访问：您的密码和令牌只会从您的头显发送到所属服务器，永远不会写入日志或放入问题报告。在应用中移除服务器会删除其信息，卸载应用会删除全部内容。

应用会连接的对象

  • 您自己的服务器。当您添加 SMB 共享、DLNA 服务器，或 Emby、Jellyfin、Plex 服务器时，Depthray 会连接该服务器以列出并串流您的文件。这些连接只携带您对该服务器的凭据，不携带其他任何内容。家庭网络中的许多此类服务器使用未加密的 http；当您输入的地址未加密时，应用会提示您。
  • Emby Connect 与 plex.tv。如果您选择用自己的账户登录 Emby 或 Plex，Depthray 会联系 Emby 或 Plex 自己的登录服务，这是这些服务向播放器提供您的服务器列表及访问令牌的方式。这些服务有各自的隐私政策。Depthray 只向它们发送登录所需的内容。
  • 您购买本应用的商店。在 Meta Quest 上，应用通过 Meta Horizon 平台确认您的账户已获授权，并通过同一平台完成免费试用后用于解锁应用的那一项应用内购买。为此它使用您的 Meta 用户 ID 和您对本应用的购买记录（如上所述），不作其他用途。在 PICO 头显上，应用以同样的方式通过 PICO 平台确认您的账户已获授权，并通过同一平台完成购买；它不向平台索取任何用户 ID，也不保留该交互的任何内容。下载与购买由各商店自己的政策约束。

除此之外，唯一的网络使用是您自己发送的问题报告，见下文。没有遥测，也不会回传任何数据。

手、眼与摄像头

手部追踪（在您允许的情况下）仅用于指向和识别捏合手势。眼动追踪（在具备该功能并由您开启的头显上）仅用于指向：您注视的位置逐帧成为指针的位置，仅此而已。应用从不保存注视数据，从不将其发送到任何地方，也不会将其写入日志或问题报告，因此不存在任何开始保存或传输它的时刻。透视画面由头显自身的系统合成；应用从不接收摄像头图像。以上内容均不会被记录、保存或传输。

日志与“报告问题”

Depthray 在头显上自己的私有存储中保存一份纯文本日志，记录它做了什么，卸载应用时一并删除。日志不记录您播放过的文件名，只记录文件类型（如“.mkv”）；您添加的服务器会在日志中被提及。应用中的“清除历史”会清空日志，日志只会随您发送的报告离开头显。“关于”页面中的“报告问题”一行会询问您发生了什么，如果您希望得到回复，还会询问您的电子邮箱地址。当您按下“发送”时，应用会把您的留言、头显型号、应用版本、最近一条性能记录和该日志发送给 Woodford XR。在您按下“发送”之前不会发送任何内容，发送内容的副本会保存在您头显的 Download/Depthray/reports 目录中，供您查看。

报告通过加密连接发送到 Woodford XR 在 Cloudflare 上运行的一个小型中转服务，再由它交给电子邮件投递服务 Resend，最后送达 Woodford XR 在 Namecheap 的支持邮箱。这三家服务商只为传递报告而处理它，也是唯一能看到报告的第三方。日志可能提及您添加的服务器，报告只有在您填写了电子邮箱地址时才会包含它。报告在问题调查期间保存在支持邮箱中，之后删除；如果您提供了邮箱地址，它只用于就该报告回复您。

儿童

Depthray 面向 13 岁及以上用户，不以儿童为对象。

来自公共机构的要求

除用户自行选择发送的问题报告外，Woodford XR 不持有任何 Depthray 用户的数据，因此几乎没有可提供的内容。对公共机构的任何要求，都会审查其法律依据，缺乏依据的予以拒绝或提出异议，答复不超出法律要求的范围，并予以记录。

您的权利与删除您的数据

申请删除您的数据：请使用您在报告中提供的电子邮箱地址，或附上足以找到相关记录的信息，写信至 support@woodfordxr.com，主题为“Delete my data”（删除我的数据）。Woodford XR 将删除其持有的您的全部问题报告和来信，并在 30 天内回复确认。索取 Woodford XR 持有的与您有关的数据副本或要求更正，也请写信至同一地址。

应用收集的两项数据。您头显上的购买与授权记录副本会在卸载应用时删除；您的 Meta 用户 ID 从不由应用或 Woodford XR 保存，因此没有可删除的内容；两者的原始数据由 Meta 或 PICO 持有，见下文。如需删除 Woodford XR 持有的任何与您有关的数据，或希望得到其不持有任何数据的确认，请按上述方式写信至 support@woodfordxr.com，您将在 30 天内得到答复。

您头显上的数据由您掌控。应用中的“清除历史”会清空播放历史和日志，移除服务器会删除其信息，卸载应用会删除 Depthray 保存的全部内容，包括试用与解锁记录。您发送过的报告副本位于 Download 文件夹中，是普通文件，您可以自行删除。

由商店持有的数据。您的 Meta 或 PICO 账户、用户 ID 和购买历史由 Meta 或 PICO 持有，而非 Woodford XR，Woodford XR 没有可删除的副本。如需删除这些数据，请使用您的 Meta 或 PICO 账户的隐私设置。如果您就此写信给 Woodford XR，它会告诉您该向何处申请。

变更

如果本政策有变更，新版本将在本地址发布并标注新日期。未在此处说明之前，应用不会开始收集新的数据。

联系方式

请写信至 support@woodfordxr.com，或访问支持页面（英文）。
